# PMO.az Next.js frontend

Responsive Next.js implementation of the supplied PMO.az Figma screens.

## Run locally

```bash
pnpm install
pnpm dev
```

## Production build

```bash
pnpm build
```

The project uses the App Router and exports a static site to `out/`.

## Routes

- `/` — Home
- `/programs` — Programs catalogue
- `/services` — Services
- `/about` — About
- `/contact` — Contact
